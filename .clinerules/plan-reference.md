> 目的：`PROJECT_PLAN.md` 约 1400 行，**禁止整文件读取**（浪费上下文且易引入无关信息）。
> 一切引用与读取都必须**按章节定位**，本文件提供章节索引与行号，便于 Cline 精确读取。

## 1. 引用格式

- 正文引用：`§5.3`、`§10.1 ③`、`§6.2 P5`。
- 读取方式：先查下表定位章节 → 用 `read_files` 带 `start_line` / `end_line` 只读该区间。
- 变更记录：接口或排期变更后，必须同步更新下表（章节行号会漂移）。

## 4. 硬约束提醒（引用 §0，不得违反）

1. 采集层（L1）、归一化层（L2）：**纯传统代码，禁止 LLM**。
2. 富化层（L3）、问答层（L4）：**必须 LangGraph 多 Agent**。
3. 所有数据模型用 **Pydantic v2**；Python 必须带 **type hints + docstring**。
4. 采集器必须继承 `BaseConnector`；归一化函数必须是**纯函数**。
5. **禁止修改 `.clineignore` 排除的目录**（`data/ logs/ docs/ .venv/ .env` 等）；
   文档只落**仓库根目录**与 `reports/`，**禁止使用 `*.csv` 作为交付格式**。
6. Python 统一 **3.11**。
